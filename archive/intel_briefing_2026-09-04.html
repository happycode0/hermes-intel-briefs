★ 2,461
Python · arXiv:2606.15971 · MIT
Overview / Mechanics

A third retrieval architecture — "SQL-Retrieval Augmented Generation" — that replaces both dense RAG and GraphRAG. It models each chunk as one event + multiple entities and builds query-time dynamic hyperedges via SQL joins, avoiding pre-built global graphs and enabling trivial incremental updates. Benchmarked as new SOTA on HotpotQA, 2WikiMultiHopQA and MuSiQue (avg 90.07% Recall@5).

Practical Utility

Local-first knowledge base for individuals and agents: document ingestion → event/entity extraction → cited multi-hop answers. Ships a desktop app, Docker stack, OpenAI-compatible endpoint, and a Knowledge MCP server (via fast `sag` CLI) that wires into Codex / Claude Code with no JWT copy-paste.

Surfacing as a credible "third architecture" narrative against GraphRAG.
