🔍 Code Scanning, SAST & Auditing

Static analysis and LLM-driven vulnerability discovery for the modern codebase.

OpenAnt

★ 750

Open-source LLM-based vulnerability discovery from Knostic. A semantic pipeline: Stage 1 detects, Stage 2 attacks, "what survives is real." Builds call graphs and context, then verifies exploitability to crush false positives. CLI + web UI; supports Go, Python and betas for JS/TS, C/C++, PHP, Ruby, Zig, Swift, Rust.

Practical utility: Proactively find verified flaws; exit-code contract (1 = findings, not failure) for CI; diff/PR/incremental scans; free scans for OSS projects.

Target audience
  • Defenders & OSS maintainers
  • AppSec teams
  • Security researchers
🔥 Trending context: 750 stars; Knostic is in the vulnerability-disclosure process for findings; arXiv paper published; Cyber Security News coverage; positions against OpenAI's Aardvark / Anthropic's Claude Code Security.

PySpector

★ 151

Graph-based SAST framework for Python with a Rust core (pyo3 + Rayon). Flow-sensitive, inter-procedural taint engine building AST, call graphs and CFGs with fixed-point taint propagation. Multi-engine: regex + AST + graph; AI-agent and supply-chain CVE rulesets.

Practical utility: Up to 18,448 lines/sec — 2.1x faster than Bandit, 3.7x faster than Semgrep; SARIF output; git pre-commit hook; CI integration; agent-skill for Claude Code/Codex.

Target audience
  • Python DevSecOps teams
  • CI/CD pipeline owners
  • Agent-driven security audits
🔥 Trending context: 151 stars but backed by a published benchmark whitepaper; rising quickly as a Rust-accelerated Python SAST alternative in the "best SAST tools 2026" roundups.

★ 11.1k

Practical utility: Vendor-agnostic detections convertible to 25+ SIEM/EDR/XDR formats via pySigma / sigma-cli / sigconverter.io; integrated by IBM QRadar, LimaCharlie, Security Onion, VirusTotal and more.

Target audience
  • Detection engineers
  • Threat hunters
  • SOC / blue teams
🔥 Trending context: 11.1k stars; de-facto community detection-engineering standard; continuously growing; new AI-agent threat rule formats (ATR) emerging alongside it.
