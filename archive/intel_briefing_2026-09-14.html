JavaScript

llmfit AlexsJones/llmfit
★ 36.5k
Rust

Overview / Mechanics

Hardware-aware CLI/TUI that inspects CPU, RAM, GPU/VRAM and accelerators, then scores 497+ models across 133 providers for fit, speed, quality and context. Recommends quantizations (GGUF/AWQ/GPTQ/EXL2), supports MoE, multi-GPU, and benchmarks real tok/s. Exposes a REST API (/api/v1/system, /api/v1/models) and Docker image.

Practical Utility

Eliminates the trial-and-error of "what model fits my machine" for local LLM operators — from MacBook Pro to multi-GPU rigs. Integrates with Ollama, llama.cpp, MLX, LM Studio.

Target Audience

  • Local-LLM enthusiasts & homelab operators
  • MLOps engineers sizing inference workloads
  • Hardware reviewers & benchmarkers
OSINT: Surged on Hacker News and YouTube ("stop guessing which LLM runs on your hardware") after covering 497 models / 133 providers. Written in safe Rust with sub-second startup; community benchmarking share feature driving rapid adoption.
llama.cpp ggml-org/llama.cpp
★ 128.2k
C / C++

Overview / Mechanics

The foundational LLM/VLM inference engine in plain C/C++ with zero dependencies. Runs on Apple Silicon (Metal), x86 (AVX/AVX512/AMX), RISC-V, and diverse backends (CUDA, HIP, Vulkan, SYCL, OpenCL, WebGPU). 1.5–8-bit integer quantization, CPU+GPU hybrid inference, built-in OpenAI-compatible server and web UI.

Practical Utility

De-facto runtime underpinning most local AI tooling (Ollama, LM Studio, etc.). Enables performant on-device inference from edge devices to datacentre GPUs.

Target Audience

  • Every local-LLM project (transitive dependency)
  • Embedded / edge AI engineers
  • Researchers needing portable inference
OSINT: Continues as the bedrock of the local-AI ecosystem; 128k+ stars with commits within the last 24h. New model support (Qwen 3.5/3.6) and broadened backend matrix keep it the reference inference layer.
