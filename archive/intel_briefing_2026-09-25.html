NousResearch/hermes-agent

★ 248.7k
Python · MIT · Self-improving autonomous agent
Overview / Mechanics

The self-improving AI agent by Nous Research. Persistent cross-session memory, a closed learning loop that authors and self-improves skills, scheduled cron automations, and a gateway reaching Telegram, Discord, Slack, WhatsApp, Signal and CLI from one process. Runs on 7 terminal backends (local, Docker, SSH, Singularity, Modal, Daytona, Vercel Sandbox) and delegates parallel subagents. Provider-agnostic via hermes model.

Practical Utility

A persistent, async agent that never forgets — the reference implementation of the "agent that grows with you." Ideal for long-running ops, research and personal automation on a $5 VPS or GPU cluster.

  • AI engineers building persistent agent infrastructure
  • Self-hosters and privacy-focused operators
  • Security teams needing auditable, container-isolated agents
Trending ContextReleased 25 Feb 2026; crossed 175,000 GitHub stars in under four months (22k stars + 242 contributors within weeks). Coverage by AI Builder Club and Bitcoin.com frames it as the open answer to Claude Code's memory gap. Direct lineage of this very briefing's author.
