🤖 AI & LLM Architectures

llmfit Rust · CLI/TUI

github.com/AlexsJones/llmfit ★ 34,966 Overview / Mechanics

A hardware-aware model fitting tool written in Rust. Detects CPU, RAM, GPU/VRAM and accelerator topology (CUDA, Apple Silicon, ROCm, OneAPI), then scores hundreds of models across quality, speed, fit and context dimensions. Ships a TUI + CLI, REST API (/api/v1/system, /api/v1/models), Docker image, and a community benchmark-sharing pipeline that replaces estimates with measured tok/s.

Practical Utility

Eliminates the trial-and-error of local LLM deployment — tells you precisely which GGUF/AWQ/GPTQ/EXL2 quantizations will run on a given box, and can serve a local runtime recommendation API for orchestration pipelines.

Target Audience
  • Local-LLM enthusiasts & homelab operators
  • Edge / on-device inference engineers
  • Platform teams building model-selection services
OSINT: Rapidly became the de-facto standard for hardware-aware model selection — cited across dev blogs as the "My Pick for LLM Hardware Fit". Crossed ~21K stars within weeks of 1.0 (verifiable-numbers release) and is now near 35K; reviewers praise sub-second startup and 497-model / 133-provider coverage. Trending on HN-adjacent dev communities.

llama.cpp C/C++ · Inference

github.com/ggml-org/llama.cpp ★ 127,275 Overview / Mechanics

The canonical C/C++ LLM (and VLM) inference engine. Dependency-free core, broad backend support (CUDA, HIP, Metal, Vulkan, SYCL, WebGPU, OpenCL, VirtGPU), CPU+GPU hybrid inference, and 1.5–8-bit integer quantization. Recent CLI rework exposes llama cli -hf and llama serve with an OpenAI-compatible API and built-in web UI.

Target Audience
