Principal Security Architecture & Intelligence Analysis — 7-Category Repository Sweep
Report Date: 2026-09-16 Model: tencent/hy3-preview (OpenRouter) Analyst: Mr Delly Bot (Hermes Agent) Repositories Profiled: 27 Window: 24–48h star velocity + commit activity
Executive Summary. The trending board is dominated by a sharp AI-security collision: OpenAI's Codex Security and Knostic's OpenAnt are riding the September 2026 AI-safety discourse (OpenAI/Anthropic/Google talks per TechCrunch, Sep 15) and the rising tide of agent-borne supply-chain attacks (e.g. the "CodeRelay" cluster of 12 malicious VS Code extensions). Local-model tooling — llama.cpp, llmfit, llamafile — continues its steady ascendancy, while self-hosting stacks (awesome-selfhosted, Compose-Examples) remain the community's gravitational centre. Notably, Hermes Agent (the framework this analyst runs upon) is the fastest-growing open agent project of 2026.

🪽 Hermes, Agents & Local Models

★ 246K

Runs on $5 VPS → GPU cluster; Telegram/Discord/Slack/WhatsApp/Signal gateway; seven terminal backends; scheduled cron automations. (The framework this analyst is honoured to serve, Sir.)

Real TUI, sub-agent delegation, MCP integration, skill system, and a built-in cron scheduler with multi-platform delivery — production agent infra, not a toy.
Target Audience

  • Security operations & automation engineers
  • Organisations needing private, portable agents
OSINT — Why TrendingFastest-growing open-source agent framework of 2026 — ~220K+ stars within six months of its Feb 25, 2026 launch; Trendshift #1 daily/weekly/monthly across all languages. Latest v0.21.3 (Sep 14, 2026); ~5,800 commits since v0.20.0. Pulling developers from commercial frameworks.
ggml-org / llama.cpp
★ 128.5K
C/C++ · MIT
LLM (and VLM) inference in plain C/C++ with no dependencies; minimal-setup, state-of-the-art performance across Apple Silicon, x86 (AVX/AVX512/AMX), RISC-V, CUDA, HIP, Vulkan, SYCL, WebGPU. 1.5–8-bit integer quantisation; CPU+GPU hybrid inference.
Practical Utility
The substrate beneath most local-AI tooling — single binary, OpenAI-compatible server, built-in web UI; runs models from Hugging Face in one command.
Target Audience
  • Local-model enthusiasts & researchers
  • Edge / embedded AI engineers
  • Tooling builders (Ollama, LM Studio, etc.)
OSINT — Why TrendingPerennial #1 local-inference engine; sustained velocity from new-model support (Qwen 3.5/3.6, GGUF ecosystem) and a vast downstream dependency tree.
AlexsJones / llmfit
★ 36.7K
Rust · MIT
Hardware-aware LLM fitter: detects CPU/RAM/GPU/VRAM, scores 497+ models across 133 providers on quality, speed, fit & context, and tells you what actually runs — with benchmark contribution back to the community. TUI, CLI, REST API, Docker.
Practical Utility
Eliminates the trial-and-error of "will this model fit my machine"; integrates with Ollama, llama.cpp, MLX. Sub-second startup; Rust 2024, no unsafe code.
Target Audience
  • Local-LLM deployers
  • Homelab & workstation owners
  • MLOps / capacity planners
OSINT — Why TrendingGrew ~21K→36K+ across 2026; widely cited by local-AI creators as the de-facto standard for hardware-aware model selection. Frequent crates.io releases (1.1.15, Sep 10).
mozilla-ai / llamafile
★ 26K
C++ · Apache-2.0
Distributes and runs LLMs as a single file by fusing llama.cpp with Cosmopolitan Libc — one executable runs locally on most OSes/arches with no install. Includes whisperfile for single-file speech-to-text.
Practical Utility
The simplest path to a runnable model: chmod +x model.llamafile && ./model.llamafile. v0.10 build system now tracks latest llama.cpp.
Target Audience
  • Developers shipping local models
  • Educators & demo builders
  • Privacy-first end users
OSINT — Why TrendingMozilla.ai "llamafile returns" revival (2026 blog); the single-file distribution model regained attention as model portability became a hiring/enterprise concern.

🔒 CyberSecurity & AI Security

★ 10.7K

Target Audience

  • Security researchers
OSINT — Why TrendingSurging amid the Sep 2026 AI-safety discourse — TechCrunch (Sep 15) reported OpenAI, Anthropic & Google in high-level safety talks. Rapid growth since its Jul 2026 launch; directly competes with Anthropic's Claude Code Security.
knostic / OpenAnt
★ 749
Python / Go · Apache-2.0
Open-source LLM-based vulnerability discovery. "Stage 1 detects. Stage 2 attacks. What survives is real." A multi-phase pipeline (parse→enhance→analyse→verify→report) that actually exploits candidate flaws to cut false positives/negatives. Free scans for OSS.
Practical Utility
CI-ready exit-code contract (0=clean, 1=findings, 2=error); diff/PR/staged scans; supports Go, Python, JS/TS, C/C++, PHP, Ruby, Zig, Swift, Rust.
Target Audience
  • Open-source maintainers
  • Defensive security teams
  • Vulnerability researchers
OSINT — Why TrendingOpen-sourced by Knostic (Gadi Evron); now on arXiv as the first open LLM vuln-discovery project. Timed to the "AI-discovered vulnerabilities" wave — e.g. the CodeRelay cluster of 12 malicious VS Code extensions (Aug 2026).

★ 9.8K
C++ · Apache-2.0
The open-source web application firewall engine (libmodsecurity v3) — platform-independent, SecRules language parser, signature + anomaly scoring, PCRE2 regex, libinjection SQLi/XSS, JSON logging. Connectors for Nginx/IIS separate.
Practical Utility
Defends web apps at the edge via OWASP CRS; C/C++ and Python binding APIs; sub-module build (libinjection, mbedtls).
Target Audience
  • Web application security teams
  • Platform / SRE engineers
  • WAF rule authors
OSINT — Why TrendingFoundational, continuously maintained WAF; steady activity reflects OWASP CRS updates and the ever-present need for edge protection. (Note: Trustwave sponsorship ended Jul 2024 — community-maintained since.)
